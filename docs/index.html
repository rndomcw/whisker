Whisker

Android Studio's Logcat, as a small desktop app. Read your app's logs, filter them the way you already know, and see the device screen right next to them.

Download for Windows View on GitHub

Free and open source · Windows 10 and 11 · Portable version

Why Whisker

Everything you open Android Studio for, when all you need is the log.

Great for test benches, QA, and anyone working on the device rather than the code.

Looks like Studio's Logcat

The same columns and colors: time, PID, a colored tag, the package and a level badge, plus PROCESS STARTED and ENDED markers.

Studio's filter syntax

tag:, package:, level:, -tag: to exclude, regex, is:crash and more, with suggestions, favorites and history.

Follows your app

Pick packages by name and keep their logs across restarts and new PIDs. Whisker waits for an app that hasn't started yet.

Screen mirroring

The device screen next to the log, with mouse and keyboard control, powered by the built-in scrcpy server. Nothing to install.

Screenshots and recordings

Annotate, crop and pixelate screenshots; record MP4 and trim it without re-encoding. Copy straight to Slack or Teams.

Fast with chatty devices

Each tab keeps 200,000 lines and draws only what's on screen, so it stays smooth at thousands of lines a second.

Filters

Find the lines that matter

Type a query like in Android Studio. Combine keys, exclude noise, and save the filters you use every day.

package:com.example.app level:warn -tag:Choreographer
  • Select several packages or processes at once.
  • Right-click a line to exclude its tag, package, or every line with the same message.
  • Ctrl+Space suggests tags, packages and levels.
Find

Search without losing context

Ctrl+F highlights matches in place, without hiding any lines, so you can read what happened around them.

  • Step through matches with Enter or F3; the count keeps up with new lines.
  • Match case or search with a regular expression.
Get started

Up and running in a minute

Install Whisker

Download the installer and run it. It installs for your account in one click, with no admin rights, and keeps itself up to date.

Have adb ready

Whisker uses adb from Google's SDK Platform-Tools. With Android Studio you already have it; otherwise Whisker shows you where to get it.

Plug in your device

Turn on USB debugging, connect the device and accept the prompt. Logs start streaming right away.

FAQ

Questions

Windows says "Windows protected your PC". Is it safe?

Whisker isn't code-signed yet, so SmartScreen warns about it the first time. Click More info → Run anyway. The installer is built from the public source code by GitHub Actions, and updates are verified against their SHA-512 checksum before they install.

Do I need to install scrcpy?

No. Whisker bundles the scrcpy server, which runs on the device, and has its own client built in. You only need adb.

Does Whisker collect any data?

No. It talks to adb and your device. The only network request is the update check against GitHub, which you can turn off in Help → Automatically Check for Updates.

Is there a version for macOS or Linux?

Not yet; Whisker is Windows-only for now. It's built with Electron, so other platforms are possible. Open an issue if you'd use one.

My device isn't listed. What should I check?

Run adb devices in a terminal. If it shows unauthorized, unlock the device and accept the USB debugging prompt. If nothing shows, try another cable or USB port, since some cables only charge.

More tips are in the troubleshooting guide.
